# MATLAB Onramp Certification & Projects 📐

A collection of coursework, scripts, and completion credentials from the official MATLAB Onramp course by MathWorks.

---

## 📂 Repository Contents

* **`matlab_gettingstarted_certificate.pdf`**: Official completion certificate for finishing the MATLAB Onramp foundational course.
* **Hands-On Scripts & Projects**: Practice scripts and data visualization exercises completed throughout the course modules, including the *Compare Stellar Spectra* final project.

---

## 🛠️ Skills Covered

* **MATLAB Environment**: Navigating the desktop, managing workspaces, and using built-in documentation.
* **Vectors & Matrices**: Performing array operations, indexing, and data manipulation.
* **Data Visualization**: Plotting 2D graphs, customizing labels, titles, and formatting plots.
* **Scripts & Functions**: Writing modular code and automating mathematical workflows.

---

## 💻 How to View / Run

1. Download or clone this repository to your local machine.
2. Open **MATLAB** or access **MATLAB Online** via MathWorks.
3. Open any `.m` script files or view the certificate PDF directly in your browser or viewer.
